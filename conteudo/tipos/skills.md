---
resumo: Skills ensinam o assistente a fazer uma tarefa do jeito certo, como consultar o FosterMCP ou montar um briefing.
---
Uma **skill** é um pacote de instruções que o assistente consulta sozinho quando o pedido combina com ela. Você instala uma vez e ela passa a valer nas conversas novas.

- **Claude Desktop:** envie o arquivo .zip. Depende do plano.
- **Claude Code e Codex:** copie a pasta da skill para a pasta de skills.
- **ChatGPT:** cole as instruções num Projeto ou num GPT personalizado.

O passo a passo está em [Como instalar uma skill](/tutoriais/instalar-skill/).
