### Claude Desktop

Use um **Projeto do Claude**: as instruções valem para todas as conversas dentro dele.

1. **Copie as instruções.** Clique em **Copiar as instruções**.
2. **Crie o projeto.** No Claude, abra **Projetos › Novo projeto** e dê um nome.
3. **Cole as instruções.** Em **Instruções do projeto**, cole o texto e salve.
4. **Converse dentro do projeto.** Com o FosterMCP conectado ao Claude Desktop, o agente consulta os seus dados.

### ChatGPT (Projetos e GPTs)

1. **Copie as instruções.** Clique em **Copiar as instruções**.
2. **Cole num Projeto ou num GPT.** No Projeto, use o menu **⋯** › **Instruções**. No GPT personalizado, use **GPTs › Criar › Configurar › Instruções** e salve como **Somente eu**.

> [!IMPORTANT]
> Em Projetos e GPTs o FosterMCP não está disponível: o agente trabalha só com o que você escrever. Siga as regras da empresa sobre dados de clientes.

### ChatGPT (aba Codex)

1. **Crie uma pasta só para o agente.** Por exemplo, dentro de **Documentos**.
2. **Salve o AGENTS.md.** Clique em **Baixar AGENTS.md** e coloque o arquivo nessa pasta, com esse nome.
3. **Abra a pasta no Codex.** No app do ChatGPT, na aba **Codex**, abra essa pasta e converse ali.

### Claude Code

1. **Crie uma pasta só para o agente.**
2. **Salve como CLAUDE.md.** Clique em **Baixar AGENTS.md**, coloque o arquivo na pasta e renomeie para **CLAUDE.md**.
3. **Abra o Claude Code nessa pasta.** As instruções valem para as conversas ali.
