1. Abra uma **conversa nova** no seu assistente com o FosterMCP conectado: Claude Desktop, aba Codex do ChatGPT, Claude Code ou Cursor.
2. Clique em **Copiar o prompt** e cole na conversa.
3. Troque o que está entre **[colchetes]** pelo seu caso, como o nome ou o código do cliente.
4. Envie e confira a resposta: ela deve dizer de onde veio cada dado e de quando ele é.

Se o assistente disser que não encontra o FosterMCP, veja [como conectar](/apps/fostermcp/#como-conectar-ao-seu-assistente).
