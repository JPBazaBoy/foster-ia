## Para que serve

O Hermes Agent é um agente de código aberto que guarda memória entre as conversas. Com o FosterMCP, ele poderia acompanhar a carteira e as conversas dos clientes ao longo das semanas. Este modelo ainda está em preparação.

## O que precisa

```requisitos
- texto: Hermes Agent instalado
  nota: A configuração de servidores MCP fica em ~/.hermes/config.yaml
- texto: FosterMCP instalado, com as fontes conectadas
- texto: Experiência com terminal e arquivos YAML
```

Antes de publicar o passo a passo, falta testar o uso da memória com dados de clientes: o que o Hermes guarda, onde guarda e por quanto tempo.
