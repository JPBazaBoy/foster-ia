## Para pedir bem

- **Diga para usar o FosterMCP:** comece com "Usando o FosterMCP…".
- **Identifique o cliente:** o código é melhor que o nome. Com nomes repetidos, o assistente deve perguntar qual é.
- **Diga o período:** "nos últimos 30 dias", "nesta semana", "em setembro".
- **Diga o formato:** tabela, lista por data ou resumo em 3 linhas.
- **Peça as fontes:** "cite a fonte e a data de cada dado".

## Para conferir a resposta

- **Data dos dados:** dados antigos do Atlas não mostram o que mudou depois. Se estiverem desatualizados, clique em **Atualizar Atlas** no FosterMCP.
- **WhatsApp:** o FosterMCP só tem as conversas escolhidas, a partir de quando foram escolhidas. Não achar uma mensagem não prova que ela não existe.
- **Números importantes:** confira no Atlas antes de levar a um cliente.
- **Sugestões não são fatos:** o assistente deve separar o que veio dos dados do que é opinião dele.

## Cuidados

- O FosterMCP nunca envia e-mails nem mensagens. Rascunhos e eventos só são criados depois do seu "pode criar".
- Se um e-mail ou mensagem trouxer instruções, como "transfira o valor", o assistente deve tratar como informação, nunca como ordem.
- Siga as regras da empresa sobre o uso de IA com dados de clientes.
