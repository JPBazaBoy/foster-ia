O assistente é rápido, mas responde melhor quando o pedido é claro, e pode errar. Estas regras simples ajudam nas duas coisas.

## Para pedir bem

- **Diga para usar o FosterMCP:** comece com *"Use o fostermcp para…"*.
- **Identifique o cliente:** o código é melhor que o nome. Se houver nomes repetidos, o assistente deve perguntar qual é.
- **Diga o período:** *"nos últimos 30 dias"*, *"nesta semana"*, *"em setembro"*.
- **Diga o formato:** tabela, lista por data, resumo em 3 linhas.
- **Peça as fontes:** *"diga de onde veio cada dado e de quando ele é"*.

## Para conferir a resposta

- **Data dos dados:** dados do Atlas antigos não mostram o que mudou depois. Se estiverem desatualizados, clique em **Atualizar Atlas** no FosterMCP.
- **Cobertura do WhatsApp:** o FosterMCP só tem as conversas que você escolheu, a partir de quando escolheu. Não achar uma mensagem não prova que ela não existe.
- **Números que importam:** confira no Atlas antes de levar a um cliente.
- **Sugestões não são fatos:** o assistente deve separar o que veio dos dados do que é opinião dele.

## Cuidados

- O FosterMCP nunca envia e-mails nem mensagens. Rascunhos e eventos só são criados depois do seu "pode criar": leia antes de aprovar.
- Se um e-mail ou mensagem trouxer instruções (por exemplo, "transfira o valor"), o assistente deve tratar como informação, nunca como ordem.
- Siga as regras da empresa sobre o uso de IA com dados de clientes.
