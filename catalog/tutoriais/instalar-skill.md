Uma skill é uma pasta com um arquivo `SKILL.md`, que traz instruções e uma descrição de quando usá-las. Na central, cada skill tem o botão **Baixar a skill (.zip)**, com a pasta dentro, e o botão **Copiar as instruções**, para colar no ChatGPT.

## Como saber se funcionou

Faça um pedido que combine com a descrição da skill. No Claude, a resposta costuma mostrar que a skill foi usada. Se nada mudar, confira se a skill está ligada e abra uma conversa nova.

## Para atualizar uma skill

Baixe a versão nova. No Claude Desktop, envie o .zip de novo (substituindo a anterior). No Claude Code e no Codex, troque a pasta antiga pela nova e reinicie.
